Spiky Adventures :
Jeu de Plateforme 2D

Unity 2D C# Aseprite / Photoshop

01. Conception Générale

Inspiré du gameplay de Mario, Spiky Adventures est un jeu de plateforme en 2D où le joueur traverse plusieurs niveaux en évitant des obstacles piquants et des ennemis. Ce projet m'a permis d'appréhender l'ensemble des étapes de création d'un jeu vidéo, de la conception à l'export.

02. Les Niveaux (Level Design)

La conception des niveaux a été réalisée avec les Tilemaps (grilles de tuiles) d'Unity. J'ai dessiné mes propres sprites (dalles, plateformes, décors) avec Aseprite et Photoshop pour créer 4 niveaux distincts.

03. Scripting – Le Tilemap

Ce script contrôle les plateformes mobiles qui suivent un chemin de waypoints.

Analyse du code

Ce script gère le mouvement des plateformes sur un circuit fermé de points de passage :

  • Waypoints : circuit fermé de l'index 0 → n-1 → 0.
  • Mouvement fluide : interpolation linéaire entre chaque point.
  • Gizmos : visualisation du chemin dans l'éditeur Unity pour faciliter le level design.
MovingPlatform.cs Unity C# Script 

                using System.Collections;
                using System.Collections.Generic;
                using UnityEngine;

                public class MovingPlatform : MonoBehaviour
                {
                    [SerializeField] private Transform[] waypoints;
                    public float speed = 1f;
                    private int currentIndex = 0;

                    void Start()
                    {
                        if (waypoints.Length > 0)
                            transform.position = waypoints[0].position;
                    }

                    void FixedUpdate()
                    {
                        if (waypoints.Length == 0) return;

                        int nextIndex = (currentIndex + 1) % waypoints.Length;
                        Vector2 target = waypoints[nextIndex].position;

                        transform.position = Vector2.MoveTowards(
                            transform.position, target, speed * Time.deltaTime
                        );

                        if (Vector2.Distance(transform.position, target) < 0.01f)
                            currentIndex = nextIndex;
                    }

                    private void OnDrawGizmos()
                    {
                        if (waypoints == null || waypoints.Length < 2) return;

                        Gizmos.color = Color.blue;
                        for (int i = 0; i < waypoints.Length; i++)
                        {
                            Gizmos.DrawWireSphere(waypoints[i].position, 0.2f);
                            int next = (i + 1) % waypoints.Length;
                            Gizmos.DrawLine(waypoints[i].position, waypoints[next].position);
                        }
                    }
                }

04. Le Personnage

Le protagoniste (Spiky) est un petit personnage orange. Il peut sauter (plus haut en maintenant la touche), se déplacer horizontalement, et détruire ses ennemis en leur sautant dessus — à la manière de Mario.

05. Scripting – Les Mouvements

Mouvement.cs Unity C# Script 

                using System.Collections;
                using System.Collections.Generic;
                using UnityEngine;

                public class PlayerMovement : MonoBehaviour
                {
                    [Header("Mouvement")]
                    [SerializeField] private float speed = 7f;
                    [SerializeField] private float jumpForce = 12f;
                    [SerializeField] private float maxJumpTime = 0.25f;

                    private float horizontal;
                    private bool isJumping;
                    private float jumpTimeCounter;
                    private bool isFacingRight = true;

                    [Header("Collision")]
                    [SerializeField] private LayerMask groundLayer;
                    [SerializeField] private Transform groundCheck;
                    [SerializeField] private float groundCheckRadius = 0.2f;

                    private Rigidbody2D rb;
                    private bool isGrounded;

                    void Start() { rb = GetComponent(); }

                    void Update()
                    {
                        horizontal = Input.GetAxis("Horizontal");
                        isGrounded = Physics2D.OverlapCircle(groundCheck.position, groundCheckRadius, groundLayer);

                        Flip();

                        if (Input.GetButtonDown("Jump") && isGrounded)
                        {
                            isJumping = true;
                            jumpTimeCounter = maxJumpTime;
                            rb.linearVelocity = new Vector2(rb.linearVelocity.x, jumpForce);
                        }

                        if (Input.GetButton("Jump") && isJumping)
                        {
                            if (jumpTimeCounter > 0)
                            {
                                rb.linearVelocity = new Vector2(rb.linearVelocity.x, jumpForce);
                                jumpTimeCounter -= Time.deltaTime;
                            }
                            else isJumping = false;
                        }

                        if (Input.GetButtonUp("Jump")) isJumping = false;
                    }

                    void FixedUpdate()
                    {
                        rb.linearVelocity = new Vector2(horizontal * speed, rb.linearVelocity.y);
                    }

                    void Flip()
                    {
                        if ((isFacingRight && horizontal < 0) || (!isFacingRight && horizontal > 0))
                        {
                            isFacingRight = !isFacingRight;
                            Vector3 scale = transform.localScale;
                            scale.x *= -1;
                            transform.localScale = scale;
                        }
                    }
                }

06. Scripting – Pièges & Ennemis

Analyse du code

  • Détection de collision : Utilise OnCollisionEnter2D pour détecter le contact avec le joueur.
  • Mécanique Mario-like : Si le joueur tombe sur le spike vu du dessus (vélocité Y négative), le spike est détruit.
  • Game Over : Dans tout autre cas de collision, le niveau est rechargé.
SpikeHead.cs Unity C# Script 

                using UnityEngine;
                using UnityEngine.SceneManagement;

                public class SpikeHead : MonoBehaviour
                {
                    private void OnCollisionEnter2D(Collision2D collision)
                    {
                        if (collision.gameObject.CompareTag("Player"))
                        {
                            // Vérifie si le joueur arrive du dessus (comme dans Mario)
                            if (collision.relativeVelocity.y < 0)
                            {
                                // Le joueur a écrasé l'ennemi → Destruct.
                                Destroy(gameObject);
                                // Petit rebond optionnel
                            }
                            else
                            {
                                // Mort du joueur → Restart
                                SceneManager.LoadScene(SceneManager.GetActiveScene().name);
                            }
                        }
                    }
                }
