Home Lab : Infrastructure
Système & Réseau

Debian Docker Tailscale / Nginx

01. Défi technique : Contexte et Problématique

  • Contexte : Mon hébergement en résidence CROUS impose des contraintes réseau strictes : pas d'accès à la box, impossibilité d'ouvrir des ports. L'objectif : créer un réseau privé virtuel accessible depuis l'extérieur.
  • Solution : Mise en place de Tailscale (VPN Mesh) et Nginx Proxy Manager en tant que reverse proxy interne.
  • Résultat : Une infrastructure isolée mais interconnectée, permettant l'hébergement de services web et l'administration à distance.

02. Architecture Système & Services

  • OS : Installation et configuration de Debian 12 sans interface graphique pour une empreinte mémoire minimale.
  • Administration : Gestion complète en ligne de commande via SSH sécurisé par authentification par clé.
  • Stockage réseau : Mise en place d'un serveur de fichiers Samba pour le partage cross-platform (Windows/Linux).

03. Virtualisation & Containerisation (Docker)

  • Supervision : Déploiement de Portainer, une interface web permettant de gérer les conteneurs Docker graphiquement et de monitorer leurs logs.
  • Dashboard : Mise en ligne d'un tableau de bord personnalisé avec Dashy pour centraliser l'accès à tous les services.
  • Filtrage DNS (Pi-hole) : Déploiement en tant que résolveur DNS bloquant les pubs et les trackers.

04. Sécurité Réseau & Optimisation

  • VPN Mesh : Tailscale offre une connexion chiffrée de bout en bout, me permettant d'accéder au serveur sans exposer de ports sur le réseau CROUS.
  • Proxy inverse : Nginx Proxy Manager gère les noms de domaine locaux et l'accès HTTPS avec génération automatique de certificats SSL (Let's Encrypt).

Bilan & Compétences acquises

Le projet Home Lab m'a permis de concevoir une infrastructure complète en partant de zéro, malgré les contraintes réseau. J'ai renforcé mes compétences en administration Linux, virtualisation Docker et sécurisation des accès.
